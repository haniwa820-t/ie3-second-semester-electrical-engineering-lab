\section{用語を一つずつ理解する}\label{sec:auto1}
\begin{terms}
\term{クロック・エッジ}{計数を進める周期信号と、その立上り・立下り。カウンタは指定されたエッジで更新するので、両エッジを二回として数えない。}
\term{分周・進数}{入力をn回数えて一巡すれば、次段に渡す周期はn倍になる。10進と6進の段をつなぐと60回で一巡する。}
\term{2進数・BCD}{2進数4ビットは0〜15。BCDは十進一桁の0〜9だけを符号化する。数字の表示にはそのBCDをデコーダへ渡す。}
\term{桁上げ}{一桁が一巡するタイミングで次の桁を一つ進めること。任意の出力端子をつなげばよいのではなく、周期とエッジを確認する。}
\term{リセット}{計数状態を所定の値へ戻す操作。開始時の手動リセットと、24検出による自動リセットを区別する。}
\term{非同期・伝搬遅延}{入力エッジから出力変化まで少し時間がかかる。非同期カウンタでは段の変化が順に伝わり、途中に一時的な状態が生じ得る。}
\term{境界試験}{通常の計数だけでなく09→10、59→00、23→00のような桁上げ・リセット条件を試すこと。時計の確認に特に重要である。}
\end{terms}
\section{六桁を一段ずつたどる}\label{sec:auto2}
\subsection{秒と分は10進と6進の組合せ}
秒一の位が0〜9を回り、一巡すると秒十の位が進む。十の位は0〜5を回り、一巡すると分一の位へ進む。
分も同じ構成で60分ごとに時へ渡す。
7490は2分周と5分周の接続で10進になる。
7492の全体は12分周であり、時計で使う6進は6分周部分への入力を選ぶ。IC名だけで進数を判断せず端子図を確認する。
\subsection{時は24の検出で一巡させる}
二つの十進桁をつなぐだけでは00〜99まで進む。
時十の位が2、時一の位が4に達する条件を検出して両桁を零へ戻す。
24は短時間だけ内部に現れる可能性がある。表示が00に見えても、リセット信号の極性・幅・遅延を別に確認する。
\subsection{555は時間のものさし}
同じ分周比でも、最初のクロックが正確でなければ時計全体の進み方がずれる。
抵抗・容量の公差と調整範囲を確認し、周期を測ってから時計へ接続する。
高速試験は桁上げ確認に役立つが、実時間での時計精度とは別の確認である。

\section{カウンタと数の表現}\label{sec:auto3}
4ビットの2進数は0〜15を表す。BCDは0000〜1001を十進一桁に対応させ、1010以降を使わない。
7セグメントデコーダはBCDを数字に対応した点灯パターンに変換する。
\[
 1\,\mathrm{Hz}\ \xrightarrow{\div10}\ 0.1\,\mathrm{Hz}
 \ \xrightarrow{\div6}\ \frac1{60}\,\mathrm{Hz}.
\]
6進と10進の組合せで60進となる。時は単なる60進ではなく24でリセットする。
\section{ICの接続で確認すること}\label{sec:auto4}
\begin{itemize}
\item 7490：2分周出力$Q_A$を次の分周段の入力に接続すると10進となる。
\item 7492：全段の組合せは12分周。6進に使うときは6分周部分へのクロック入力を選ぶ。
\item リセットの組合せ条件、計数エッジ、電源端子、使わない入力の扱いを資料の端子図で確認する。
\item 24検出は時十の位の2と時一の位の4を検出する。単に各桁を独立の10進にしただけでは24時間時計にならない。
\end{itemize}
\section{555の設計例}\label{sec:auto5}
\[
 R_B=\frac{1/(0.693fC)-R_A}{2}.
\]
例として$f=1\,\mathrm{Hz},C=2.2\,\mu\mathrm{F},R_A=3.3\,\mathrm{k}\Omega$なら
$R_B\simeq326\,\mathrm{k}\Omega$。これは設計練習であり、実験指定の素子値とは区別する。
可変抵抗の最大値、固定抵抗、容量公差を確認し、調整可能な範囲を見積もる。

\section{タイミングと不具合の考え方}\label{sec:auto6}
非同期カウンタでは出力が同時に変化しない。途中の瞬間的な状態を組合せ論理で検出すると短いパルスを生じる場合がある。
表示が期待どおりでも、桁上げのエッジとリセット波形をオシロスコープで確認する。
配線は電源を切って行い、段ごとに確認してから接続する。
\section{測定からレポートへ：時系列で確かめる}\label{sec:auto7}
\subsection{分周を電圧波形で確かめる}
入力クロックと次段に渡す出力を同じ時間軸で描き、入力何エッジに対して次段が一回進むか数える。
出力がHIGHの時間と、一巡して同じエッジになる周期を区別する。
資料指定の10進$Q_D$、6進$Q_C$が次段に与えるエッジを確認する。
\subsection{時計の誤差を計算する練習}
仮に555の周期が1.01秒なら、時計上の3600カウントに要する実時間は3636秒。
したがって表示が1時間進むまでに36秒余分にかかる。これは練習例であり、実験で1時間試験をした結果ではない。
分周比が正しくても、基準周期のずれはすべての桁へ引き継がれる。
\subsection{結果表に書くこと}
境界直前の表示、与えたクロック数、次の表示、リセットの有無を一組で記す。
23:59:59から一秒後だけでなく、その後の00:00:01も確認すればリセット後の再開を調べられる。
回路変更や加速用入力を使った場合は、どの段へ接続したか明記する。

\section{確認問題}\label{sec:auto8}
\begin{enumerate}
\item 1 Hz入力を10分周し、さらに6分周した信号の周期を求める。\answerline
\item 23:59:59の次の一秒で、どの段に桁上げとリセットが必要か。\answerline
\item 7492のすべての分周部分を接続した場合、分周比はいくらか。\answerline
\item 555のCが理論値より10\%大きいと、他の条件が同じ場合の周波数は何倍か。\answerline
\end{enumerate}
\section*{解答の目安}\label{sec:auto9}
(1) 60秒。(2) 秒と分の両桁が循環し、時が24を検出して00へ戻る。
(3) 12分周。(4) $1/1.1\simeq0.909$倍。
\section*{配線の予習欄}\label{sec:auto10}
資料の回路で、6進段の入力・出力、手動リセット、24検出の信号を色分けする。
