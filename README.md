# Electronic Engineering Lab Manuals

電子工学実験（3年後期）の教材PDFを実験テーマ別に整理したリポジトリです。

## 内容

- `IE3_exp*/`: A4サイズに調整した実験別PDF

元のスキャン画像、中間PDF、作業用出力はリポジトリに含めていません。

## 実験テーマ

- A: 回路網
- B: 共振回路
- C: 電源回路
- D: 発振回路
- E: マルチバイブレータ
- F: カウンタ回路
- G1: マイコンによるステッピング・モータ制御
- G2: マイコンによる7セグメントLED表示制御
- H: PICを用いたフルカラーLED制御
- I: A/D変換とD/A変換
- J: PLCによるシーケンス制御
